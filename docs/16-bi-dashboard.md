# Step 16 - Power BI / Tableau Dashboard Artifact

The repository includes a BI-ready KPI data dictionary and CSV template under `bi/`. These artifacts are designed for direct import into Power BI or Tableau.

Recommended pages:
1. Executive Overview - invoice volume, average confidence, compliance pass/fail.
2. Processing Operations - daily volume, processing status and processing time.
3. Quality & Compliance - confidence distribution, data-quality score, compliance status.
4. Governance - audit events and role-sensitive activity.

Suggested slicers: date, document type, status, vendor and compliance status.
