# Evaluation evidence to add

The repository currently contains the documented evaluation evidence and BI-ready dataset.

The project work also produced machine-readable result artifacts locally under the evaluation results area. Add the available final, actually executed files here when submitting, especially:
- invoice accuracy report
- OCR accuracy/retention report
- processing-time report
- invoice quality/confidence report
- multilingual OCR report
- handwritten OCR report

Do not add stale, duplicate, or experimental outputs. Keep only the final evidence corresponding to the submitted evaluation run.
