# DocuMind AI - Final Submission

This folder is the submission index for the **AI-Powered Intelligent Document Processing Platform (DocuMind AI)** Industry Project.

## Submission structure

1. **01_Project_Report** - final industry-project report based on the supplied report reference format.
2. **02_PowerBI_Dashboard** - native Power BI PBIX and dashboard evidence.
3. **03_Evaluation_Reports** - invoice accuracy, OCR retention, confidence, compliance, processing-time and SLA/refresh evidence.
4. **04_Testing_Documents** - test design, test cases, scenarios and test evidence.
5. **05_Governance_and_Lineage** - data dictionary, governance, lineage, RBAC and audit evidence.
6. **06_MLOps_and_Explainability** - MLflow, drift/retraining trigger and SHAP explainability evidence.
7. **07_Deployment_Evidence** - Docker/Kubernetes/Azure runtime evidence where externally executed.
8. **08_Execution_Video** - final end-to-end execution recording.
9. **09_Supplementary_Artifacts** - supporting datasets, screenshots and additional project evidence.

## Important evidence boundary

The repository contains the implemented application and documented local evaluation evidence. Live Azure/Kubernetes runtime evidence, production BI scheduler evidence, underlying LLM weight fine-tuning and automatic retrained-model replacement are not claimed unless separately executed and captured.

The final Power BI PBIX and execution video should be retained in the institute/company submission package.
